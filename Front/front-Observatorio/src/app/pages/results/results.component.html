Reporte de Resultados

Descripción

Este informe tiene como objetivo evaluar el nivel de implementación de prácticas de calidad dentro del proceso de desarrollo, conocer el nivel de esfuerzo que invierten las organizaciones de software en su implementación, y finalmente conocer el estado general de los mayores desafíos que enfrentan al implementar estas prácticas. Para cada uno se utiliza la scala LIKERT con el fin de dar una descripción detallada para facilitar su comprensión y aplicación en la evaluación de calidad.
